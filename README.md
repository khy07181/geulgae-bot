# 글개 봇 (geulgae-bot)

글쓰기 스터디 "글개"의 주간 목표·벌금 관리 디스코드 봇.

매주 참여자를 정해 블로그 글 목표를 설정하고, 일요일 23:59(KST) 마감까지 달성하지 못한 만큼 벌금을 부과·집계한다. 인증된 글과 벌금 내역은 채널에 공개로 기록된다.

## 명령

| 명령 | 설명 |
|---|---|
| `/목표설정 참여자 [개수] [벌금] [주차]` | 주간 목표 생성·갱신 (주차: 이번주/다음주) |
| `/인증 링크` | 글 링크 인증. 사이클 스레드 안에서 하면 그 주차로 귀속 |
| `/현황` | 참여자별 진행률과 마감까지 남은 시간 |
| `/벌금현황` | 누적 벌금 잔액과 총액 |
| `/벌금조정 대상 금액 [사유]` | 벌금 수동 조정 (양수=부과, 음수=삭감) |
| `/참여 [대상]` | 이번 주 참여자로 등록 (본인 또는 다른 멤버) |
| `/참여취소 [대상]` | 참여 취소 (마감 전 + 인증한 글이 없을 때만) |
| `/닉네임 이름` | 글개 Archive(홈페이지)에 표시할 내 이름 등록 (20자 이하, 본인만) |

봇이 알아서 하는 일 (KST):

- **매일 00:01** — 마감이 지난 주를 정산하고 미달자에게 벌금 부과
- **화요일 10:00** — 이번 주 목표가 없으면 [참여하기] 버튼이 달린 공지 게시
- **일요일 10:00** — 아직 목표를 못 채운 참여자에게 마감 리마인더
- 자동 작업이 실패하면 인증 채널에 ⚠️ 알림을 남긴다

## 글개 Archive (홈페이지)

봇과 같은 Worker가 비밀 경로로 아카이브를 서빙한다. 링크는 멤버끼리만 공유한다.

- `/s/<PAGE_TOKEN>/` — 아카이브: 전체 통계와 연·월로 묶은 주차별 인증 글
- `/s/<PAGE_TOKEN>/<연도>` — 그 해 결산: 멤버별 발행·연속 달성, 월별 추이, 올해의 키워드, 올해의 기록, 전원 달성·벌금 (연중엔 진행 현황판)
- 작성자는 `/닉네임`으로 등록한 이름으로만 표시되고, Discord ID는 노출되지 않는다
- 미등록자는 "익명 A"처럼 표시되고, 해를 걸치는 주는 마감일(일요일)의 연도 결산에 들어간다

**키워드**: 인증 시 봇이 글 본문을 읽어 Workers AI로 키워드를 뽑아 저장한다(본문은 저장하지 않음). 기존 글 소급은 일회성 배치로 — 다 될 때까지 `after`를 응답의 `lastId`로 바꿔 반복 호출:

```bash
curl -X POST "https://<워커 주소>/s/<PAGE_TOKEN>/keywords-backfill?after=0"
```

처음 켜는 법: 추측 어려운 긴 랜덤 문자열을 만들어 `wrangler secret put PAGE_TOKEN`으로 등록하면 그 순간부터 경로가 열린다 (미등록이면 404). `/닉네임` 커맨드는 `npm run register`를 다시 실행해야 디스코드에 나타난다.

## 운영

- **배포**: `main`에 푸시하면 GitHub Actions가 테스트 후 자동 배포한다 (저장소 시크릿 `CLOUDFLARE_API_TOKEN` 필요)
- 데이터는 D1 하나가 전부이며 별도 백업은 두지 않는다 (소규모 신뢰 기반 모임, 실수 복구는 D1 Time Travel 30일로 충분)
