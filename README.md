# 글개 봇 (geulgae-bot)

글쓰기 스터디 "글개"의 주간 목표·벌금 관리 디스코드 봇.

매주 참여자를 정해 블로그 글 목표를 설정하고, 일요일 23:59(KST) 마감까지 달성하지 못한 만큼 벌금을 부과·집계한다. 인증된 글과 벌금 내역은 채널에 공개로 기록된다.

## 명령

| 명령 | 설명 |
|---|---|
| `/목표설정 참여자 [개수] [벌금] [주차]` | 주간 목표 생성·갱신 (주차: 이번주/다음주) |
| `/인증 링크` | 글 링크 인증. 사이클 스레드 안에서 하면 그 주차로 귀속 |
| `/현황` | 참여자별 진행률과 마감까지 남은 시간 |
| `/벌금현황` | 누적 벌금 잔액과 총액 |
| `/벌금조정 대상 금액 [사유]` | 벌금 수동 조정 (양수=부과, 음수=삭감) |
| `/참여취소 [대상]` | 참여 취소 (마감 전 + 인증한 글이 없을 때만) |

봇이 알아서 하는 일 (KST):

- **매일 00:05** — 마감이 지난 주를 정산하고 미달자에게 벌금 부과
- **화요일 10:00** — 이번 주 목표가 없으면 [참여하기] 버튼이 달린 공지 게시
- **일요일 10:00** — 아직 목표를 못 채운 참여자에게 마감 리마인더
