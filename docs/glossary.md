# 용어 사전

새 용어는 코드보다 먼저 여기에 추가한다. 코드 이름은 아래 영문 대응어를 따른다.

| 용어 | 뜻 |
|---|---|
| 아카이브 | 인증 글 전체를 연·월·주차로 모아 보여주는 홈페이지 입구. 표시 이름 '글개 Archive'. 옛 이름 '서재' (VIS-001, PAGE-006) |
| 결산 | 한 해의 글·달성·벌금 집계 뷰. 연중엔 진행 현황판 (VIS-001) |
| 키워드 | 결산에 싣는 그 해의 관심 주제. 글 제목·본문에서 자동 구성 (PAGE-008) |
| 닉네임 | 아카이브에 표시되는 이름. 본인이 `/닉네임`으로 등록 (PAGE-002) |
| 비밀 경로 토큰 | 아카이브 접근을 여는 긴 랜덤 문자열. Worker secret으로 보관 (PAGE-003) |
