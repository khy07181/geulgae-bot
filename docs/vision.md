# 비전 (요약)

원본은 `docs/decisions/05-vision.md`의 VIS 결정이다. 이 문서는 읽기 좋게 풀어 쓴 요약이다.

## 정체성

글쓰기 스터디 "글개"의 주간 목표·벌금 관리 디스코드 봇. 여기에 스터디가 쌓아 온 기록(인증 글·결산)을 흘려보내지 않고 상시로 보이게 하는 **글개 홈페이지**를 더한다. 봇 본체의 설계 권위는 `docs/specs/2026-07-20-geulgae-bot-design.md`이고, 결정 중심 개발은 홈페이지부터 적용한다(PRIN-004).

## 목표

- 디스코드 스레드에 묻히는 주간 기록(글 51건+, 정산)을 홈페이지에서 영구적으로 볼 수 있게 한다 (VIS-001).
- 연말 결산을 채널 공지가 아니라 연도별 결산 뷰로 남긴다. 연중에는 진행 현황판으로 동작한다 (VIS-001, BOT-001).

## 비목표

- 이번 주 실시간 현황 페이지 — 디스코드 `/현황`과 중복 (VIS-001).
- 글 본문 수집·검색 — 링크 아카이브까지만.
- 결산 링크의 채널 공지 cron — 두지 않는다 (BOT-001).
- 완전 공개 URL — 비밀 경로로 시작하고, 공개 전환은 멤버 동의 후 별도 결정 (PAGE-001).

## 성공 기준

- 멤버가 비밀 링크로 서재·결산을 열어 본다.
- Discord 숫자 ID가 페이지 어디에도 노출되지 않는다 (PAGE-001).
